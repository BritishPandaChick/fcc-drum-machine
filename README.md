# Drum Machine
freeCodeCamp Frontend Libraries project

## Tech Stack 
* HTML
* CSS
* Bootstrap
* React

## Instructions 
1. Clone this repo or download the zip file. 
2. Run ```npm start``` to start the app. 
3. Click the drum pad elements to start playing sounds.
